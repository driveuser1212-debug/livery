#CACTUS0319 — CUSTOM IFS LIVERIES
=================================

IMPORTANT
---------
This pack is ONLY for Minecraft 1.12.2 with the compatible version of
Immersive Vehicles / Immersive Flight Simulator (IFS).

Do not install this pack on other Minecraft versions.

INSTALLATION INSTRUCTIONS
-------------------------

1. BACK UP YOUR ORIGINAL MOD
   Make a backup copy of your original IFS mod JAR before changing anything.
   If something goes wrong, you can restore the backup.

2. OPEN THE MOD JAR
   Use 7-Zip or WinRAR to open the IFS mod JAR.
   Do not extract it into a random folder and leave the files outside the JAR.

3. REPLACE THE JSON DEFINITIONS
   Inside the mod, find the folder named:
       jsondefs

   Delete the existing JSON definition files in that folder and replace them
   with all of the new JSON definition files included with this livery pack.
   Keep the folder structure and filenames as supplied.

4. ADD THE TEXTURES
   Inside the mod, find the folders named:
       items
       liveries

   Copy each texture from this pack into its matching folder in the mod.
   Put item/preview textures in the appropriate items folder and aircraft
   livery textures in the appropriate liveries folder. Preserve the supplied
   subfolders and filenames.

5. SAVE THE MOD
   Save the changes in 7-Zip or WinRAR and close the archive.
   If the archive program asks whether to update the JAR, confirm the change.

6. TEST IN MINECRAFT
   Launch Minecraft 1.12.2 with the compatible IFS / Immersive Vehicles version.
   Check that the new livery options appear and that each aircraft displays
   the correct texture.

TROUBLESHOOTING
---------------
- If a livery does not appear, check that every supplied JSON definition was
  copied into jsondefs and that filenames and folder paths were preserved.
- If a livery option appears but the aircraft has the wrong texture, check that
  the texture is in the correct items or liveries folder.
- If Minecraft crashes or the mod fails to load, restore your backup and
  check that you are using the compatible Minecraft 1.12.2 mod version.
